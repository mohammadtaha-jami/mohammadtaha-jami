B v3.8 IZLANDINGPAGES

Project: Business Directory & Micro-Landing Pages — a production-grade WordPress plugin that turns a WordPress install into a directory of niche-aware micro-landing pages, with subscriptions, owner dashboards, and an Elementor bridge.

پروژه: دایرکتوری کسب‌وکار و صفحات فرود خرد — یک افزونه وردپرس سطح تولید که یک نصب وردپرس را به دایرکتوری صفحات فرود خرد و نیچ‌آگاه تبدیل می‌کند، همراه با اشتراک، داشبورد مالک و پل الیمنتور.

VERSION 3.8.2 STATUS Production OWNER Toocheshm DEV MohammadTaha HosseinZadeh Choose a chapter from the tabs → یک فصل از تب‌ها انتخاب کنید

BizLandingPages is a production-grade WordPress plugin that transforms a WordPress installation into a directory of micro-landing pages. Small businesses register, choose a subscription tier, and receive mobile-first business cards or classic listings with niche-gated modules — shop, scheduling, or portfolio — depending on their category and plan. The plugin owns its own CPTs, roles, payment flow, template hierarchy, and an Elementor widget/dynamic-tag bridge.

BizLandingPages یک افزونه وردپرس سطح تولید است که یک نصب وردپرس را به دایرکتوری صفحات فرود خرد تبدیل می‌کند. کسب‌وکارهای کوچک ثبت‌نام می‌کنند، یک سطح اشتراک انتخاب می‌کنند و بر اساس دسته‌بندی و پلن خود، کارت کسب‌وکار موبایل‌محور یا لیستینگ کلاسیک همراه با ماژول‌های نیچ‌محور (فروشگاه، نوبت‌دهی یا نمونه‌کار) دریافت می‌کنند. افزونه، CPT، نقش‌ها، جریان پرداخت، سلسله‌مراتب قالب و پل ویجت/تگ پویای الیمنتور خود را در اختیار دارد.

The plugin bootstraps as a singleton that wires four layers — Core (settings, templates, SEO, PWA, sync), Finance (plans, subscriptions, payment, ZarinPal), Users (auth, registration, dashboard, marketer, favorites), and Modules (shop, niche, scheduling, appointments) — plus an Elementor bridge for widgets and dynamic tags. Everything runs inside WordPress core with MySQL/MariaDB as the datastore.

افزونه به‌صورت singleton بوت می‌شود و چهار لایه را به هم متصل می‌کند — هسته (تنظیمات، قالب‌ها، SEO، PWA، سینک)، مالی (پلن‌ها، اشتراک، پرداخت، زرین‌پال)، کاربران (احراز هویت، ثبت‌نام، داشبورد، بازاریاب، علاقه‌مندی) و ماژول‌ها (فروشگاه، نیچ، نوبت‌دهی، وقت‌ها) — به‌همراه پل الیمنتور برای ویجت‌ها و تگ‌های پویا. همه‌چیز درون هسته وردپرس با MySQL/MariaDB به‌عنوان مخزن داده اجرا می‌شود.

BizLandingPages does not add any custom SQL tables — the schema lives entirely inside WordPress core tables: three custom post types, two hierarchical taxonomies, and a wide set of user meta, post meta, and serialized options.

BizLandingPages هیچ جدول SQL سفارشی اضافه نمی‌کند — طرح داده کاملاً درون جداول هسته وردپرس قرار دارد: سه پست‌تایپ سفارشی، دو taxonomy سلسله‌مراتبی و مجموعه‌ای گسترده از user meta، post meta و آپشن‌های سریالایز‌شده.

Deployment Checklist

چک‌لیست استقرار

  1. 1.Set merchant_id to a production ZarinPal UUID.
  2. 2.Configure sync_api_secret with a strong random string.
  3. 3.Assign routing pages (auth, payment, callback, dashboard).
  4. 4.Enable HTTPS — required for ZarinPal and PWA.
  5. 5.Flush rewrite rules: wp rewrite flush --hard.
  6. 6.Verify cron is running: wp cron event list.
  1. ۱.مقدار merchant_id را به شناسه واقعی زرین‌پال تنظیم کنید.
  2. ۲.sync_api_secret را با یک رشته تصادفی قوی مقداردهی کنید.
  3. ۳.صفحات مسیریابی (ورود، پرداخت، callback، داشبورد) را تخصیص دهید.
  4. ۴.HTTPS را فعال کنید — برای زرین‌پال و PWA الزامی است.
  5. ۵.Rewrite rule ها را flush کنید: wp rewrite flush --hard.
  6. ۶.اجرای کرون را بررسی کنید: wp cron event list.
